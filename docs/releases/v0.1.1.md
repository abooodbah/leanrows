# LeanRows 0.1.1

LeanRows 0.1.1 is a Windows installer patch release. The native viewer and its
large-file engine are unchanged from 0.1.0.

## Installer corrections

- Fixes a fresh-install failure in the 0.1.0 package when PowerShell attempted
  to write a registry default value whose name is the required empty string.
- Preserves every earlier value when multiple registrations share one registry
  key, and uses an exact writable per-user key when uninstall restores or
  removes a direct default.
- Keeps LeanRows in **Open with** for `.csv`, `.tsv`, `.jsonl`, `.ndjson`, and
  `.log`.
- For a supported extension with no protected Explorer `UserChoice`, records
  the prior per-user direct default and makes LeanRows the direct per-user
  default.
- Preserves every protected `UserChoice`. The optional `-OpenDefaultApps`
  switch opens Windows Default Apps when manual confirmation is wanted.
- Makes reinstalls idempotent: LeanRows is never recorded as its own previous
  handler.
- On uninstall, restores or removes only direct defaults that still point to
  LeanRows. A handler selected later by the user is preserved.
- Does not register or change `.txt`.

## Download

This release provides two attachments:

```text
LeanRows-v0.1.1-windows-x64-unsigned.zip
LeanRows-v0.1.1-windows-x64-unsigned.sha256
```

LeanRows 0.1.1 is not Authenticode-signed. Windows may display a warning for a
downloaded executable. Verify the ZIP against the `.sha256` attachment from
this same release:

```powershell
Get-FileHash .\LeanRows-v0.1.1-windows-x64-unsigned.zip -Algorithm SHA256
```

After extraction, validate and run the per-user installer:

```powershell
.\install.ps1 -ValidateOnly
.\install.ps1
```

Installation requires no administrator privileges. LeanRows is added to the
current user's Start menu and Installed Apps list.

## Application behavior and limits

The viewer retains the 0.1.0 behavior and boundaries: Windows x64 only;
read-only local CSV, TSV, JSONL, NDJSON, log, and text viewing; bounded
previews; no telemetry or network retrieval; and no editing, saving, export,
sorting, filtering, regular expressions, SQL, archives, or tail/follow mode.

The [README](https://github.com/abooodbah/leanrows#readme) contains the full
usage boundary. Security-sensitive findings should use
[private vulnerability reporting](https://github.com/abooodbah/leanrows/security/advisories/new).
