# LeanRows 0.1.0

LeanRows 0.1.0 is the first public release of a native, read-only Windows
viewer for large row-oriented files. It prepares a bounded viewport without
loading the complete source into memory and continues indexing in the
background.

## Highlights

- Opens CSV, TSV, JSONL, NDJSON, log, and text files from local Windows
  volumes.
- Preserves quote-aware CSV and TSV record boundaries, including embedded
  newlines and escaped quotes.
- Displays bounded CSV and TSV fields in independent native columns.
- Uses fixed-capacity adaptive checkpoints and bounded viewport previews rather
  than an in-memory offset or object for every row.
- Provides demand-driven literal Find with next/previous navigation, checked
  absolute-row jumps, bounded tab-delimited clipboard copy, and native file
  drag-and-drop.
- Detects source replacement or revision changes before stale offsets can be
  reused.
- Escapes invalid UTF-8 bytes and marks truncated previews instead of silently
  normalizing input.
- Provides a native Win32 interface with keyboard focus, system colors,
  per-monitor DPI handling, and accessibility names.
- Includes no telemetry, account, updater, network retrieval, or bundled web
  runtime.

## Download

This release provides two attachments:

```text
LeanRows-v0.1.0-windows-x64-unsigned.zip
LeanRows-v0.1.0-windows-x64-unsigned.sha256
```

The ZIP is portable and contains `leanrows.exe`, optional per-user install and
uninstall scripts, the MIT license, the unsigned-build notice, and a manifest
with the size and SHA-256 of every payload.

## Verify and run

LeanRows 0.1.0 is not Authenticode-signed. Windows may display a warning for a
downloaded executable. Verify the ZIP against the `.sha256` attachment from
this same release:

```powershell
Get-FileHash .\LeanRows-v0.1.0-windows-x64-unsigned.zip -Algorithm SHA256
```

After extraction, launch `leanrows.exe` directly or validate and run the
optional per-user installer:

```powershell
.\install.ps1 -ValidateOnly
.\install.ps1
```

The installer does not require administrator privileges and does not silently
replace existing Windows file defaults. It adds LeanRows to the current user's
Start menu and Installed Apps list.

## Frozen release measurements

The final local aggregate QA run for the Windows release candidate recorded:

- **Cold full-process-tree private bytes:** 2,424,832 bytes (2.31 MiB; three
  samples).
- **Document-open full-process-tree private bytes:** 3,280,896 bytes (3.13
  MiB; three samples with `large.log`).
- **Document-open full-process-tree working set:** 18,677,760 bytes (17.81
  MiB; three samples with `large.log`).
- **Deterministic seek and document-smoke result:** 35/35 completed: 24/24
  deterministic viewport seeks across three fixtures with zero mismatches, and
  11/11 positive or expected-failure document-smoke cases.
- **Sparse logical-scale result:** first-viewport checks passed for structurally
  verified 1 GiB and 10 GiB sparse logical files.

These observations are specific to the recorded Windows host and workload.
They are not universal RAM or startup guarantees. The deterministic seek
matrix exercises the architecture-spike command-line entry point, not automated
random-seek interaction through the native owner-data control. The sparse files
were descriptor-verified synthetic fixtures allocated at 128 KiB each; they
were not scanned completely, and full-file SHA-256 hashes were not computed.

## Snapshot behavior

The active source is opened without write access. LeanRows also excludes
in-place write sharing so bytes cannot change underneath indexed offsets. An
application that appends to, truncates, or rewrites the same file may receive a
sharing violation while LeanRows holds it open. Atomic replacement remains
possible; LeanRows detects the new path identity and requires reload.

## Known limits

- Windows x64 is the only 0.1 release target.
- The package is unsigned.
- Format selection is based on the file extension.
- JSONL and NDJSON are displayed as line-oriented records; 0.1 does not provide
  schema validation or a JSON-tree view.
- Remote and UNC paths, reparse points, device paths, editing, saving, export,
  sorting, filtering, regular expressions, SQL, archives, and tail/follow mode
  are not supported.
- Bounded previews can omit part of a long record or field and mark the display
  as truncated.

The [README](https://github.com/abooodbah/leanrows#readme) provides the complete
usage boundary. Security-sensitive findings should use
[private vulnerability reporting](https://github.com/abooodbah/leanrows/security/advisories/new).
