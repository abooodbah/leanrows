# LeanRows 0.7.0

LeanRows is a free Windows viewer for CSV, TSV, JSON Lines, log and Excel
files too large for Excel. It reads the file without loading it into memory and
never changes it. In 0.7.0 the interface is also available in Simplified
Chinese and Japanese.

Everything from 0.6.1 works as before.

## Languages

- LeanRows follows your Windows display language. Japanese picks Japanese,
  Simplified Chinese picks Simplified Chinese, and every other language,
  Traditional Chinese included, keeps English.
- Settings (`Ctrl+/`) has a Language choice: System, English, 简体中文 or
  日本語. The choice applies at once and is saved next to the theme, as
  `Language` under `HKCU\Software\LeanRows`.
- Menus, the toolbar, find, go to row, sorting, the status bar, messages and
  the keyboard shortcut list are translated. Your data is shown as before, and
  key names, file names and numbers stay as they are.
- Text that Windows writes, such as a file access error, comes in the language
  Windows uses.

If you upgrade on a Japanese or Simplified Chinese Windows, the interface
changes language on the first start. Choose English in Settings to keep the
old interface.

## Measured

On a GitHub Actions Windows runner, with a 250 MB file open, peak memory is
about 0.1 MiB higher than in 0.6.1 (16.5 MiB against 16.4 MiB), which matches
the size of the added text tables. Start-up time is unchanged. The executable
is 1,164,800 bytes in a local build (0.6.1: 1,062,400 bytes). The runs are in
#59.

## Known gaps

- The Chinese and Japanese text was translated and checked by back
  translation, not reviewed by a native speaker.
- Traditional Chinese has no interface of its own; it keeps English, and
  简体中文 can be chosen in Settings.
