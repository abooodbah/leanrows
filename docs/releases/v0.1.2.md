# LeanRows 0.1.2

LeanRows 0.1.2 redesigns the native Windows interface while preserving the
bounded, read-only document engine and the installer safeguards introduced in
0.1.1.

## Interface redesign

- Introduces a warm, opaque visual system aligned with the LeanMark family:
  dark ink, one blue action accent, restrained one-pixel rules, and deliberate
  spacing.
- Replaces the permanent legacy menu with a responsive top bar. File identity,
  search, and document commands adapt across narrow, default, and wide window
  layouts.
- Moves literal search into the main window. The field includes Match case,
  previous, and next controls, while `Ctrl+F`, `F3`, and `Shift+F3` remain
  available from the keyboard.
- Keeps the virtual owner-data grid as the row surface. Cell requests remain
  cache lookups; file reads, decoding, and indexing continue on the bounded
  worker path.
- Provides System and Light appearance choices. When Windows high contrast is
  active, LeanRows uses the applicable system colors. This release does not
  claim a native dark theme.
- Retains the standard Windows title bar, snap behavior, per-monitor DPI
  handling, visible focus, and native accessibility semantics.

## Behavior retained

LeanRows remains a Windows x64, read-only viewer for local CSV, TSV, JSONL,
NDJSON, log, and text files. It does not load a whole-file object model, alter
the source, send telemetry, or retrieve network content. Editing, saving,
export, sorting, filtering, regular expressions, SQL, archives, and tail/follow
mode remain outside the 0.1 boundary.

The per-user installer continues to register LeanRows in **Open with** for
`.csv`, `.tsv`, `.jsonl`, `.ndjson`, and `.log`. It changes a direct
per-user default only when no protected Explorer `UserChoice` exists,
preserves later user choices, and does not register or change `.txt`.

## Download

This release provides two attachments:

```text
LeanRows-v0.1.2-windows-x64-unsigned.zip
LeanRows-v0.1.2-windows-x64-unsigned.sha256
```

LeanRows 0.1.2 is not Authenticode-signed. Windows may display a warning for a
downloaded executable. Verify the ZIP against the `.sha256` attachment from
this same release:

```powershell
Get-FileHash .\LeanRows-v0.1.2-windows-x64-unsigned.zip -Algorithm SHA256
```

After extraction, validate and run the per-user installer:

```powershell
.\install.ps1 -ValidateOnly
.\install.ps1
```

Installation requires no administrator privileges. LeanRows is added to the
current user's Start menu and Installed Apps list.

## Validation and source

The tagged workflow rebuilds the application on Windows, runs the pinned
quality and native smoke gates, validates deterministic packaging, and
publishes the unsigned ZIP with its checksum. The
[validation status](https://github.com/abooodbah/leanrows/blob/v0.1.2/docs/VALIDATION_STATUS.md)
separates frozen-release evidence from earlier candidate results.
