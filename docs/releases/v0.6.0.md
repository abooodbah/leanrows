# LeanRows 0.6.0

LeanRows 0.6.0 lets you hide columns from the view. Requested by @Dobatymo
in #39.

Everything from 0.5.1 works as before.

## Hide columns

- Right-click a column header and choose Hide column. Show all columns, on
  the same menu, brings every hidden column back.
- The More menu has both commands, with a Hide column submenu that lists the
  shown columns, so they work from the keyboard too.
- Hiding a column changes the view only. The file is not changed and nothing
  is saved. Each tab keeps its own hidden columns until the file is reloaded
  or another file or sheet is shown in it.
- Hidden columns are left out of `Ctrl+C` copies and of horizontal
  scrolling.
- The last shown column cannot be hidden, so text, log and JSONL files, which
  show one Preview column, have nothing to hide.
- Sort by a column and then hide it, and the rows stay in that order. The
  status bar marks the sorted column as hidden.
- Find still searches whole rows, hidden columns included, and the status bar
  says so while a search result is shown.
- CSV, TSV and Excel `.xlsx` sheets all work. Sheet columns keep their
  letters.

LeanRows never loads whole columns into memory, so hiding one saves screen
space rather than memory. For the rows on screen, LeanRows skips decoding the
hidden fields.

## Measured

On the maintainer's laptop, 0.5.1 and 0.6.0 built the same way, with a
generated 20,000,001-row CSV of seven columns and 1,494,444,479 bytes, three
alternating runs each:

| Measure | 0.5.1 | 0.6.0 |
| --- | --- | --- |
| Peak working set when indexing finished | 18.42 to 18.45 MiB | 18.40 to 18.45 MiB |
| The same, with four of seven columns hidden | | 18.45 to 18.53 MiB |
| Peak working set after 200 Page Downs | 18.72 to 18.81 MiB | 18.75 to 18.82 MiB |
| Time to index the file | 20.2 to 21.3 s | 21.5 to 22.5 s |
| Executable size, local build | 1,024,512 bytes | 1,062,400 bytes |

Hiding columns made no difference these runs can separate from noise.

## Known gaps

- Find searches hidden columns. Skipping them would mean splitting every
  matching row into fields first.
- Menus use the system menu colours, so in a dark theme the header menu is
  light. This was already true of the sort menu.
- The native workflow test for hiding columns runs in the local sort smoke
  test, not in CI.
- Sorting and Find do not work on `.xlsx` workbooks yet. Sorting says so
  instead of sorting.
- The installer and the Store package do not register `.xlsx`.
